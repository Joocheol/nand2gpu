# KoPubWorld 글꼴

이 책은 『금융공학의 이해』와 같은 KoPubWorld Pro OTF 6종을 로컬 `fonts/` 폴더에서 사용한다.

필요한 파일:

- `KoPubWorld Batang_Pro Light.otf`
- `KoPubWorld Batang_Pro Medium.otf`
- `KoPubWorld Batang_Pro Bold.otf`
- `KoPubWorld Dotum_Pro Light.otf`
- `KoPubWorld Dotum_Pro Medium.otf`
- `KoPubWorld Dotum_Pro Bold.otf`

글꼴 파일은 한국출판인회의의 [KoPubWorld 공식 배포 페이지](https://www.kopus.org/biz-electronic-font2/)에서 내려받는다. 이 공개 저장소는 글꼴 바이너리를 재배포하지 않으며 `fonts/*.otf`를 Git에서 제외한다.

로컬 빌드와 CI는 위 파일을 `fonts/`에 준비한 뒤 실행해야 한다.
