# 장별 샘플 원고

샘플은 완성 원고가 아니라 설명 방식과 장 사이 연결을 검증하기 위한 초안이다. 현재 여섯 샘플 모두 계산 과정과 장말 `이번 장의 선택과 비용`을 포함한다.

| 장 | 검증 목적 | 문서 |
|---:|---|---|
| 1 | 일상 규칙 → 진리표 → NAND 구현 | [가능한 경우를 모두 적으면 함수가 된다](ch01-truth-table-nand.md) |
| 8 | 일렬 합과 나무형 합, work·span·시그마 | [여덟 개의 수를 더하는 두 가지 순서](ch08-sum-work-span-sigma.md) |
| 10 | 조각별 함수와 SIMT 실행 묶음 | [같은 식 안에서 서로 다른 길을 고를 때](ch10-simt-execution-groups.md) |
| 11 | 그래픽 GPU에서 GPGPU·AI로 이어진 역사적 전환 | [어떤 계산을 고정하고 어떤 계산을 바꿀 수 있게 둘까](ch11-graphics-to-ai.md) |
| 16 | 첫 완결 행렬 곱셈과 앞 개념 회수 | [행렬의 한 칸은 곱셈과 합이다](ch16-matrix-multiplication.md) |
| 17 | 블록화·타일링과 데이터 이동 | [큰 행렬을 블록으로 보아도 같은 행렬이다](ch17-matrix-tiling.md) |

샘플의 세부 판단은 [독립 리뷰 색인](../reviews/README.md), 실제 집필 순서와 분량은 [진행 로드맵](../planning/roadmap.md)을 따른다.
