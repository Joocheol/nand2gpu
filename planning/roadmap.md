# 진행 로드맵

## 0단계: 기획 고정

상태: 완료 — 4부 20장, 장 순서, 행렬 도입 시점, 장별 비용 기록 원칙 고정

완료 조건:

- 목표 독자와 책이 제공할 학습 성과가 한 문단으로 명확하다.
- 책의 시작점·도착점·의도적으로 다루지 않을 범위가 정해져 있다.
- 목차의 각 장이 수학 서사와 하드웨어 서사 중 어느 단계에 속하는지 설명할 수 있다.
- 각 장에서 연산 횟수·의존 단계·데이터 이동·저장공간 중 무엇을 실제로 세는지 정해져 있다. 계산의 요구량과 기계가 제공하는 자원을 두 열로 나누고, 정밀도는 정답에서 내주는 별도 층으로 관리한다.
- 경쟁 도서와 다른 점을 한 문장으로 말할 수 있다.

산출물:

- 4부 20장 목차와 장별 인과 연결
- 장별 교육 목표
- 100단위 분량표와 장별 도해 예산
- 차별화 문장

## 1단계: 설명 방식 검증

상태: 텍스트·도해 검증 완료 — 서장·1~5장 흑백 도해 12종의 Claude 필수 수정과 재렌더링 완료

1장 진리표·NAND, 8장 합·의존 사슬·시그마, 10장 조각별 함수와 SIMT, 11장 그래픽 GPU에서 GPGPU·AI로 이어지는 전환, 제4부 입구의 첫 행렬 곱셈, 그다음 블록 행렬·타일링 장을 각각 샘플로 작성한다. 부품 설명이 수학적 질문을 압도하거나 후반부에서 갑자기 전공 수학책이 되는지 조기에 확인한다.

완료 조건:

- 비전공 독자가 정의되지 않은 용어 없이 읽을 수 있다.
- 비유와 실제 하드웨어 설명이 구분되어 있다.
- 모든 수식과 예제의 기호·계산 과정·답이 본문 안에서 완결된다.
- 장마다 같은 답을 내는 계산 방법을 비교하고 무엇의 비용이 달라졌는지 드러난다.
- 1장과 10장은 행렬을 억지로 예고하지 않아도 각자의 수학적 질문으로 완결된다. 16장은 앞 개념을 첫 행렬 곱셈에서 회수하고, 17장은 원소별 계산을 반복하지 않은 채 같은 예제를 블록화·데이터 이동 문제로 전환한다.
- 외부 검증이 필요한 기술 주장에 출처가 연결되어 있다.

## 2단계: 제1·2부 집필

준비 상태: 서장·1~5장 상세 설계 집중 리뷰 A~P, 수치 재검산, 도해 시안 12종의 Claude 필수 수정과 재렌더링 완료. TeX 골격과 공통 TikZ 스타일을 먼저 고정한 뒤 제1부 원고 집필 착수

함수의 명세와 분해에서 이진수·덧셈·곱셈으로 내려가고, 계산의 의존성·상태·명령 비트·벡터 병렬성으로 다시 올라온다. CPU·SIMD·SIMT는 부품 학습 목표가 아니라 수학적 계산을 시간과 실행 레인에 배치하는 사례로 사용한다.

핵심 위험:

- 디지털 논리·CPU 설명이 이후 계산 비용과 연결되지 않고 부품 목록으로 팽창하는 문제
- NAND가 실제 칩의 유일한 물리적 구성 요소라는 오해
- 수학적 항등식이 특정 회로 구조를 유일하게 강제한다는 오해
- 덧셈 한 번 안의 회로 경로와 여러 연산 사이의 의존 사슬을 같은 시간으로 취급하는 문제
- 16장에서 처음 쓸 시그마 기호를 8장의 작은 합에서 미리 준비하지 않는 문제

## 3단계: 제3부 집필

그래픽에서 고정 기능과 프로그램 가능 기능을 나누어 온 역사에서 출발해, 제한된 연산기에 많은 계산을 배치하는 문제와 데이터 위치·계산 순서·산술 집약도를 설명한다. 목적이 달랐던 그래픽과 딥러닝이 데이터 병렬 수치 계산이라는 모양을 공유한 지점은 역사적 전환으로 다루되, 두 작업이나 두 장치가 동일했다고 쓰지 않는다.

핵심 위험:

- NVIDIA 용어를 일반 GPU 구조로 일반화하는 문제
- 세대별 구현 수치를 불변의 원리처럼 서술하는 문제
- 지연시간 은폐와 메모리 병목을 단순한 코어 수 이야기로 축소하는 문제
- 그래픽의 실제 역사가 수학적 설명 흐름을 대신하는 문제
- 초기 GPU가 본래 행렬 곱셈 전용 장치였거나 현대 AI 가속기와 구조가 같았다는 오해
- 메모리 계층을 저장장치 이름 목록으로 설명하는 문제
- 지연시간 은폐와 메모리 계층의 일반 원리를 특정 제조사 문서만으로 설명하는 문제

## 4단계: 제4부 집필

행렬 곱셈의 첨자와 내적에서 시작해 블록 행렬·타일링, 유한 비트와 반올림, 혼합 정밀도, 행렬 곱셈·누산 전용화와 AI 가속기를 설명한다. 마지막에는 하나의 행렬 곱셈을 진리표에서 가속기까지 다시 추적한다.

핵심 위험:

- 신경망 전체가 행렬 곱셈뿐이라는 오해
- Tensor Core를 모든 AI 가속기의 일반 명칭처럼 사용하는 문제
- 낮은 정밀도가 항상 같은 정확도를 제공한다는 오해
- 정확한 실수 산술에서 성립하는 결합법칙과 유한 정밀도 계산 결과를 구분하지 않는 문제
- 타일링이 산술 연산 횟수 자체를 줄인다는 오해
- 산술 집약도의 분자·분모와 읽기·쓰기 포함 범위를 장마다 다르게 세는 문제
- 특정 행렬 연산 장치의 공개되지 않은 내부 데이터 흐름을 systolic 계열로 단정하는 문제
- CPU·GPU·TPU 같은 장치 전체를 범용성 축의 한 점으로 놓아 한 칩 안의 여러 실행 경로를 놓치는 문제

## 5단계: 독립 검토와 통합 편집

- 기술 검토: 불 함수, 산술회로, 병렬 알고리즘, 데이터 이동, GPU, 수치 표현, 행렬 가속기
- 수학 검토: 기호 정의, 항등식 적용 범위, 의존성, 연산 횟수와 깊이, 반올림 오차
- 교육 검토: 선수지식, 용어 도입 순서, 예제 완결성, 인지 부하
- 구조 검토: 장 사이의 인과관계와 반복
- 시장 검토: 제목, 부제, 경쟁 도서, 독자 기대
- 시효 검토: 특정 세대·제품에 종속된 문장 분리

## 6단계: 최종 원고 준비

- 그림 및 표 목록 확정
- 용어집과 찾아보기 후보 작성
- 인용·저작권·그림 출처 확인
- 확정 본제에 맞춘 소개문과 미확정 부제 결정
- 출판사 제안서 또는 투고 원고 구성
