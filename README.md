# 『진리표에서 GPU까지』

일반 독자를 위한 수학 중심의 계산·GPU 교양서 프로젝트입니다.

수학적으로 당연해 보이는 계산이 왜 하드웨어에서는 특정한 순서·병렬성·데이터 흐름을 요구하는지 설명합니다. 초반에는 진리표·이진수·덧셈·합·벡터처럼 각 개념에 맞는 작은 예제를 사용하고, 후반에는 이를 행렬 곱셈이라는 종합 계산에서 회수해 GPU의 병렬 실행·메모리 계층·타일링·유한 정밀도·AI 가속기로 이어갑니다.

`같은 답`은 우선 정확한 산술을 기준으로 한 표현입니다. 유한한 비트로 수를 근사하면 계산 순서가 결과를 바꿀 수 있다는 사실도 책의 핵심 주제로 다룹니다.

수학적 설명 흐름은 다음과 같습니다.

> 명세 → 분해 → 의존성 → 재배열 → 재사용 → 근사

이에 대응하는 하드웨어 구현 흐름은 다음과 같습니다.

> 조합 → 복제 → 공유 → 데이터 재사용 → 전용화

본제는 『진리표에서 GPU까지』로 확정했습니다. 4부 20장 목차와 행렬을 16장에서 처음 완결하는 구조도 독립 검토를 거쳐 고정했습니다. 부제는 실제 원고와 독자 시험을 더 진행한 뒤 확정합니다.
