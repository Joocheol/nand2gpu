# nand2gpu

일반 독자를 위한 컴퓨터 하드웨어·GPU 교양서 프로젝트입니다.

논리 게이트에서 출발해 덧셈기·곱셈기·ALU·CPU·SIMD·SIMT·GPU 메모리 계층·행렬 곱셈·AI 가속기까지, 병렬 계산 구조가 만들어지는 원리를 아래에서 위로 설명합니다.

핵심 설명 흐름은 다음과 같습니다.

> 조합 → 복제 → 공유 → 데이터 재사용 → 전용화

현재 제목과 목차는 작업안이며, 샘플 원고와 독립 검토를 거쳐 확정합니다.
