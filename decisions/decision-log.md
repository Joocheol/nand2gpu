## DEC-009: 수학 중심의 책으로 정체성 전환

- 날짜: 2026-08-26
- 상태: 확정
- 결정: 이 책을 GPU 부품을 차례로 설명하는 컴퓨터구조 입문서가 아니라, 같은 답을 내는 계산도 표현·분해·순서·병렬성·데이터 이동·정밀도에 따라 다른 비용을 갖는 이유를 쉬운 수학으로 설명하는 교양서로 설계한다.
- 대표 계산: 행렬 곱셈을 책 전체의 수학적 표본으로 사용한다. 행렬의 한 원소를 이루는 곱셈과 합을 논리 함수까지 분해하고, 다시 병렬 실행·데이터 재사용·타일링·정밀도·전용화로 올라온다.
- 주의: 모든 GPU 작업이나 모든 AI 계산이 행렬 곱셈이라고 일반화하지 않는다. GPU와 AI 가속기는 주어진 계산 및 물리적 제약에 대한 여러 설계 답의 사례다.
- 수학 서사: 명세 → 분해 → 의존성 → 재배열 → 재사용 → 근사.
- 하드웨어 서사: 조합 → 복제 → 공유 → 데이터 재사용 → 전용화.
- 부제 영향: “작은 논리 회로가 복제와 전용화를 거쳐…”는 하드웨어 부품의 확대를 앞세우므로 보류한다. “행렬 곱셈으로 이해하는 병렬 계산과 AI 가속기의 원리”도 행렬을 16장까지 미루는 구조보다 행렬을 앞세울 위험이 있어 DEC-013에서 보류했다.

## DEC-010: 수학적 질문 중심의 4부 20장 구조

- 날짜: 2026-08-26
- 상태: 일부 대체됨(DEC-011)
- 결정: 장 제목과 교육 목표는 부품 이름보다 수학적 질문을 앞세운다. CPU·SIMD·SIMT·warp·wavefront·SM·CU·메모리 계층·Tensor Core는 그 질문에 대한 구현 사례로 배치한다.
- 서장: 장 번호에 포함하지 않는 짧은 서장에서 행렬 곱셈이라는 목적지와 두 설명 서사를 먼저 보여준다. 본문 1장은 확정 제목의 약속대로 실제 진리표에서 시작한다.
- 구조: 제1부는 함수의 명세와 분해, 제2부는 계산 순서와 의존성, 제3부는 병렬 계산과 데이터 이동, 제4부는 행렬의 재사용·근사·전용화를 다룬다.
- 분량: 총 장 수는 20장으로 유지하되 부품 설명을 축소하고 행렬 곱셈, 계산 깊이, 데이터 이동, 유한 정밀도에 더 많은 지면을 배정한다.

## DEC-011: 행렬은 조기 반복 예제가 아니라 후반부의 종합 계산으로 사용

- 날짜: 2026-08-26
- 상태: 확정
- 결정: 1~15장에 같은 행렬 예제를 반복 삽입하지 않는다. 각 장은 진리표·이진수·덧셈·합·벡터·픽셀·격자처럼 해당 개념에 가장 자연스러운 작은 예제를 사용한다.
- 행렬 도입: 서장에서는 행렬 곱셈을 목적지로만 보여주고 계산시키지 않는다. 16장에서 행렬 곱셈을 처음 완결하며, 16~20장에서 앞의 개념을 종합·회수한다.
- 디지털 입문 허용 범위: 초반부가 디지털 논리 입문서처럼 보이는 것 자체는 결함으로 취급하지 않는다. 다만 부품 정의의 나열이 아니라 같은 기능의 여러 표현, 의존성, 회로 경로, 범용성의 비용을 설명해야 한다.
- Claude 리뷰 판단: 행렬을 5·10·15장에 반복하고 10장 뒤에 별도 행렬 계산 장을 신설하라는 제안은 채택하지 않는다. 6장과 7장의 병합도 필수로 보지 않는다. 반면 정확 산술 조건, 타일링 모형 가정, 계산 규약, 깊이의 층위 구분, 벤더 중립 출처 보강은 반영한다.
- `같은 답`의 조건: 정확한 정수·실수 산술의 수학적 결과와 유한 정밀도 하드웨어 결과를 구분한다. 타일링과 합의 재배열은 부동소수점 반올림 결과를 바꿀 수 있으며, 값의 크기 차이와 상쇄에 따라 차이가 낮은 자리에만 머물지 않을 수 있음을 17~18장에서 명시한다.
- 비용 장부: 연산 횟수·의존 단계·데이터 이동·저장공간이라는 네 물리 비용과, 정답에서 내주는 범위·정밀도·오차를 별도 층으로 기록한다. 서로 다른 단위를 하나의 점수로 합산하지 않는다.
- 분량 기준: 서장 5%, 제1부 22%, 제2부 22%, 제3부 23%, 제4부 28%를 작업 가설로 사용한다.

## DEC-012: 그래픽 GPU와 AI의 만남을 `목적은 달랐지만 계산의 모양이 겹친 전환`으로 설명

- 날짜: 2026-08-26
- 상태: 확정
- 결정: GPU가 그래픽을 위해 발전한 병렬·처리량 지향 구조였고, 프로그래머블 셰이더와 GPGPU를 거쳐 대규모 딥러닝 계산에도 유용해진 역사적 전환을 책의 중요한 서사로 사용한다.
- 핵심 표현: 그래픽과 딥러닝은 목적이 달랐지만 많은 데이터에 비슷한 수치 연산을 반복하고 높은 데이터 처리량을 요구한다는 계산의 모양이 겹쳤다. 이 겹침에 프로그래머블 하드웨어, CUDA 같은 범용 계산 환경, 라이브러리와 연구 생태계가 더해져 GPU가 AI의 핵심 플랫폼이 되었다.
- 피할 표현: `초기 GPU는 행렬 계산을 위해 만들어졌다`, `그래픽과 AI가 똑같은 계산이다`, `GPU와 현대 AI 가속기의 구조가 동일하다`, `순전히 우연만으로 GPU가 AI를 지배했다`고 쓰지 않는다.
- 배치: 11장에서 고정 기능·프로그램 가능 기능, 그래픽 파이프라인, GPGPU, 2012년 대규모 CNN의 GPU 학습을 실제 시간 순서로 설명한다. 16장 이후의 행렬 계산과 논리적으로 연결하되 역사와 교육 순서를 구분한다.

## DEC-013: 계산 요구량과 기계 자원을 분리하고 전용화를 데이터 경로 단위로 비교

- 날짜: 2026-08-26
- 상태: 확정
- 결정: 네 비용 장부는 `계산이 요구하는 양`으로 한정한다. 연산기 수·쓸 수 있는 시간·대역폭과 거리·가까운 용량·비트 수는 `기계가 제공하는 자원과 제약`이라는 별도 열에 기록한다. 성능과 설계 비용은 두 열의 관계에서 설명한다.
- 전용화 원칙: 반복 MAC을 전용 데이터 경로에 고정하는 일반 원리와 systolic 데이터 흐름이라는 특정 구현 계열을 구분한다. 공개 자료가 없는 Tensor Core·MFMA·XMX의 내부 데이터 흐름을 TPU MXU와 같은 계열로 단정하지 않는다.
- 비교 단위: 20장의 범용성 축에는 CPU·GPU·TPU라는 장치 전체가 아니라 실행 자원 또는 데이터 경로를 놓는다. 하나의 칩이 범용·벡터·행렬·고정 기능 경로를 함께 가질 수 있음을 명시한다.
- 기호 도입: 시그마 기호는 16장까지 미루지 않고 8장의 여덟 수 합을 먼저 완성한 뒤 도입한다.
- 부제 상태: 두 검토안 A·B를 유지하되 서로 배타적이므로 하나가 선택되기 전까지 `미확정`이다.

## DEC-014: 수정 방향 재검토 승인과 제4부 진입 샘플 분리

- 날짜: 2026-08-26
- 상태: 확정
- 결정: Claude 수정 방향 재검토의 비용 체계, 벤더 중립 출처, 기호 도입, 전용화 범주, 샘플 설명 개선을 반영한다. 부제는 두 대안 가운데 하나를 선택한 것으로 간주하지 않고 미확정으로 유지한다.
- 제4부 진입: 16장에 첫 완결 행렬 곱셈, 첨자, 시그마 회수, 독립 결과와 합의 의존성, 연산 횟수와 이론적 재사용 횟수를 배치한다. 17장은 같은 행렬의 16개 원소별 계산을 반복하지 않고 블록화와 데이터 이동만 새로 계산한다.
- 17장 자원 모형: 입력 타일 저장공간과 C 부분합 누산 공간을 분리한다. 64회 모형은 입력 8개와 결과 부분합 4개, 48회 모형은 입력 12개와 결과 부분합 4개를 전제로 한다.
- 독립 검토 정정: Claude는 48회 모형에 C 결과 타일 두 개의 동시 보존이 필요하다고 보았으나, C00을 완성해 쓴 뒤 C01을 차례로 완성하면 결과 타일 하나의 부분합만 유지해도 된다. 승인된 리뷰라도 계산 가정이 틀리면 그대로 채택하지 않는다.

## DEC-015: 연결 샘플 검토 반영과 목차 구조 고정

- 날짜: 2026-08-26
- 상태: 확정
- 결정: Claude 연결 샘플 리뷰에서 승인된 정의·표기·비교표·장말 형식·역사 출처 보강을 반영한 뒤 4부 20장, 장 순서, 16장의 첫 행렬 계산이라는 구조를 고정한다. 이후 세부 원고 검증으로 장 내부 구성은 다듬을 수 있지만, 구조를 바꾸려면 새 근거와 별도 결정을 남긴다.
- 제3부 이름: `많은 계산을 어디에 배치하고 데이터를 어떻게 옮길 것인가`로 확정한다. 11~12장은 계산 배치, 13~15장은 데이터 이동이라는 내부 흐름을 드러낸다.
- 장말 형식: 모든 장은 `이번 장의 계산 장부` 표로 끝의 핵심 비교를 기록한다. 계산 요구량, 기계 자원, 유한 정밀도, 설계 대가를 같은 행 이름과 순서로 관리한다.
- 역사 서술: 11장의 연표는 대표 이정표이지 최초 발명 연표가 아니다. 제조사 회고 자료는 범위를 제한하고, 현대 파이프라인의 고정 기능·프로그램 가능 단계 공존은 표준 문서로 별도 확인한다.
- 타일링 기준선: 128회 모형은 입력값 두 개를 순차 공급하고 부분합 하나를 보존하는 무재사용 일정이다. 64회·48회 모형과 입력 슬롯·누산 슬롯을 같은 표에서 비교한다.

## DEC-016: 서장·제1부 집필 전 수치 모형 고정

- 날짜: 2026-08-26
- 상태: 일부 대체됨(DEC-017)
- 결정: 서장과 1~5장은 [상세 설계표](../planning/preface-part1-detailed-briefs.md)의 완결 예제·계산 단위·도해 명세를 기준으로 집필한다. 제1부 22단위는 1~5장에 `4·4·5·4·5`로 배분한다.
- 2장: 같은 XOR을 NAND 4개·최장 3층과 NAND 6개·최장 4층인 두 교육 회로로 비교한다. 실제 표준 셀의 면적·지연으로 일반화하지 않는다.
- 3장: 4비트 `5+3`과 `5-3`으로 자릿값·전가산기·2의 보수·표현 범위를 연결한다. 전가산기 8행은 표로 완결하되 행마다 산문 계산을 반복하지 않는다.
- 4장: 완성 덧셈기 전체가 아니라 최종 올림 c4 회로를 비교한다. XOR·AND·OR를 2입력·게이트 수 1·지연 1로 둔 모형에서 리플은 16게이트·9층, 곱항을 공유하지 않는 펼친 미리보기는 22게이트·7층이다.
- 5장: `1011×1101=10001111`로 부분곱 16개·행 4개·행 덧셈 3번·최대 출력 8비트를 센다. ALU는 AND·OR·ADD·SUB 네 후보 중 2비트 신호로 하나를 고르는 교육 사례로 제한한다.
- 경계: 1~5장에서 행렬은 계산하지 않는다. 5장에서 회로의 시간적 재사용은 중간값을 기억해야 한다는 질문까지만 제시하고 레지스터·클럭은 6장에서 도입한다.

## DEC-017: 서장·제1부 집중 리뷰 전면 반영과 4장 경로 모형 수정

- 날짜: 2026-08-26
- 상태: 확정
- 결정: Claude의 서장·1~5장 집중 리뷰 A~P를 모두 반영한다. 4부 20장, 16장 첫 행렬 계산, 제1부 22단위와 장별 `4·4·5·4·5` 배분은 유지한다.
- 4장 경로 모형: DEC-016의 펼친 미리보기 `22게이트·7층`을 `22게이트·6층`으로 대체한다. 다섯 곱항의 준비 층을 센 뒤 `U0=T0 OR T1`, `U1=T2 OR T3`, `U2=U0 OR U1`, `c4=U2 OR T4`로 연결하는 도착 시각 고려 OR 트리를 정확한 교육 모형으로 고정한다. 다른 항 배치에서는 같은 게이트 수로 7층도 가능하므로 트리 배치 자체가 설계 선택임을 밝힌다.
- 비교의 범위: 리플 16게이트는 c1~c4를 과정에서 함께 만들지만 펼친 22게이트는 c4만 만든다. 중간 곱항을 공유하지 않고 c1~c4를 모두 펼치면 38게이트임을 공개한다. c4는 carry-out이며 현재 무부호 예제의 범위 초과를 보여주지만 signed overflow의 일반 신호는 아니다.
- 교육 흐름: 서장의 다섯 질문과 유한 조건을 세 열로 대응시키고 GPU 종점과 6~7장의 시간적 재사용 다리를 지도에 넣는다. 1장에서 NOT을 이름 붙이고 곱셈표는 질문으로 끝낸다. 2장은 문장을 그대로 옮긴 6게이트 회로 뒤에 줄인 4게이트 회로를 둔다. 3장은 carry-out과 signed overflow를 보충 상자로 분리한다. 5장은 나무형 3번·2단계와 순차형 3번·3단계를 대칭 비교하고 `고르는 일도 함수다`를 곱셈과 ALU의 경첩으로 삼는다.
- 출처: 표현과 산술회로 근거를 SRC-027과 SRC-029로 분리하고, SRC-028의 주장에 멀티플렉서 선택을 명시한다.
- 반영 기록: [Claude 서장·제1부 리뷰 반영 기록](../reviews/claude-preface-part1-brief-review-resolution-2026-08-26.md)을 변경 추적의 기준으로 사용한다.
