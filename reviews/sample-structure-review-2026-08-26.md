# 세 샘플 구조 검토 기록

- 검토일: 2026-08-26
- 대상: 1장 진리표·NAND, 10장 SIMT 실행 묶음, 18장 행렬 타일링
- 상태: 내부 구조 검토 완료, 비전공 독자 검증 미실시

## 잠정 판단

세 샘플은 `명세와 구현 → 제어 공유 → 데이터 재사용`이라는 난이도 상승을 한 책 안에서 연결할 수 있음을 보여준다. 다만 텍스트 초안만으로 도해 밀도와 실제 독자의 인지 부하는 검증할 수 없다. 현 단계에서 “설명 방식 검증 완료”로 판정해서는 안 된다.

## 1. 일반 독자의 이해를 방해하는 설명상의 문제

- 위치 또는 검토 대상: 1장 진리표·NAND 샘플
- 문제의 내용: NAND 두 개를 연결하는 과정이 문장과 표로만 제시되어 있다.
- 중요도: 중간
- 문제가 되는 이유: 이 책에서 처음 등장하는 물리적 연결 관계이므로 독자가 `첫 NAND의 출력이 둘째 NAND의 두 입력으로 들어간다`는 구조를 머릿속으로만 구성해야 한다.
- 구체적인 수정안: 진리표, NAND 하나, NAND 두 개로 만든 AND를 같은 면에 놓은 3단계 도해를 추가한다.
- 수정하지 않을 경우의 위험: 진리표와 회로 구현의 대응이 첫 장에서 끊긴다.

## 2. 일반 독자의 이해를 방해하는 설명상의 문제

- 위치 또는 검토 대상: 10장 SIMT 실행 묶음 샘플
- 문제의 내용: SIMD, SIMT, thread, warp, wavefront, 분기 발산이 짧은 구간에 연속 등장한다.
- 중요도: 중간
- 문제가 되는 이유: 9장을 읽었다는 전제에서도 회사별 용어 두 개와 실행 모델을 한꺼번에 유지해야 한다.
- 구체적인 수정안: 본문 흐름은 `독립 스레드처럼 표현 → 묶어서 실행 → 분기 발산`으로 유지하고, warp·wavefront의 폭과 독립 스레드 스케줄링은 회사별 사례 상자로 분리한다.
- 수정하지 않을 경우의 위험: 독자가 SIMT의 원리보다 용어 차이를 암기하게 된다.

## 3. 일반 독자의 이해를 방해하는 설명상의 문제

- 위치 또는 검토 대상: 18장 행렬 타일링 샘플
- 문제의 내용: 완결성을 위해 16개 원소 계산표와 8개의 블록 곱셈을 모두 제시해 본문 밀도가 높다.
- 중요도: 중간
- 문제가 되는 이유: 계산을 생략하지 않는 원칙은 충족하지만 핵심인 데이터 읽기 횟수 비교에 도달하기 전에 독자가 지칠 수 있다.
- 구체적인 수정안: 16개 원소 계산은 `계산 확인표`로 시각적으로 분리하고, 본문은 C00 한 개와 네 타일 계산을 중심으로 읽히게 한다. 계산표 자체는 삭제하지 않는다.
- 수정하지 않을 경우의 위험: 후반부가 갑자기 수학 교재처럼 느껴진다.

## 4. 선택 가능한 표현상의 개선

- 위치 또는 검토 대상: 세 샘플 공통
- 문제의 내용: 도해 없이 텍스트와 표만으로 검증했다.
- 중요도: 낮음
- 문제가 되는 이유: 회로 연결, 활성·비활성 실행 레인, 타일 재사용은 공간 관계가 핵심이다.
- 구체적인 수정안: 샘플마다 핵심 도해 한 개를 우선 제작한 뒤 추가 그림의 필요성을 판단한다.
- 수정하지 않을 경우의 위험: 불필요하게 긴 문장과 표가 그림의 역할까지 떠맡는다.

## 다음 검증

1. 비전공 독자 3~5명에게 정의되지 않은 용어, 되읽은 위치, 계산 중단 지점을 표시하게 한다.
2. 각 샘플을 읽은 뒤 한 문장 회상 질문을 사용한다.
   - 1장: 진리표와 NAND 게이트는 무엇이 다른가?
   - 10장: 스레드를 묶어 실행하면 무엇을 아끼고 무엇을 잃는가?
   - 18장: 타일링은 무엇의 횟수를 줄이는가?
3. 정답률뿐 아니라 읽기 시간과 되읽기 지점을 기록한다.
4. 독자 검증 전에는 부제를 확정하지 않는다.
