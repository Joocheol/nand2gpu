## 필수 수정 처리

| 항목 | 처리 | 반영 내용 |
|---|---|---|
| ch02-01 N의 깊이 | 반영 | `N=NAND(A,B)` 상자를 깊이 1 안내선으로 옮겼다. 방법 A는 6게이트·4층, 방법 B는 4게이트·3층을 유지한다. |
| 2입력 게이트 배선 | 반영 | ch02-01의 A·B 입력과 묶인 두 입력을 표시했다. ch04-02에는 `c₀→p₀·c₀`, `g₀→c₁`, `T₀→U₀`, `T₃→U₁`을 추가하고 대표 배선만 표시한다는 범위를 밝혔다. |
| ch05-01 축과 행 대응 | 반영 | 피승수는 높은 자리에서 낮은 자리로, 승수는 `b₀`에서 `b₃`로 읽는 방향을 표시했다. 격자 네 행을 부분곱 네 행과 각각 연결하고 `b₁=0`을 영 행으로 명시했다. |
| ch05-01 세로셈 | 반영 | 네 가수와 합을 같은 monospace·같은 오른쪽 기준선에 맞추고 `+`를 마지막 가수 왼쪽, 가로줄 위로 옮겼다. |
| SVG 렌더러 호환 | 반영 | 큰 수식의 인라인 `font` 축약을 개별 속성의 클래스로 바꿨다. 경로의 `marker-end`만으로는 ImageIO에서 화살촉이 사라지는 현상을 재현해, 일반 SVG polygon 화살촉을 함께 넣었다. |
| 제작 메모 제거 | 반영 | `흑백 시안`, 제작자용 명암 설명을 독자용 문장으로 교체했다. |

## 함께 반영한 개선

- preface-01: 두 곡선을 `가능한 계획 A/B`로 이름 붙이고, 다섯 번째 유한 조건인 시간을 별도 상자로 추가했다.
- preface-02: 올라오는 길의 여섯 상자에 1~6 단계 번호를 붙였다.
- ch01-01: 진리표 네 행 높이를 맞추고 ①~④를 표 바깥으로 옮겼다.
- ch03-01: 비트열에서 두 해석 패널까지 연결선이 실제 경계에 닿도록 고쳤다.
- ch04-01: ①~④를 `c₁~c₄` 위치에 맞추고 기다림 순서 범례를 추가했다.
- ch04-02: p·g 여덟 게이트를 1층 묶음으로 표시하고, A1·A2a 같은 제작용 이름을 실제 곱항 식으로 교체했다.

## 재검산과 렌더링

- XML 문법: SVG 12종 모두 `xmllint` 통과.
- 렌더링: SVG 12종 모두 macOS ImageIO로 PNG 변환 성공.
- ch02-01: NAND 상자 10개 = 방법 A 6개 + 방법 B 4개.
- ch04-02: 회로 상자 38개 = 리플 16개 + 펼친 식 22개. 표시 깊이 9층과 6층 유지.
- ch05-01: 한 비트 곱 표기 16개, 부분곱 행 `11, 0, 44, 88`, 합 `143` 유지.

## 판형 확정 뒤 남는 조판 조건

- 최종 인쇄 글자는 6.5pt 이상으로 한다.
- ch02-01, ch04-02, ch05-01은 우선 가로 전면 도판으로 취급하고, 판형이 정해지면 실제 배치 폭에서 다시 축소 검사를 한다.
- 회색은 진한 회색=현재 따라갈 경로, 옅은 회색=배경·명세, 흰색=일반 요소라는 원칙으로 최종 조판에서 일괄 정규화한다.
- 비전공 독자 시험은 이번 반영의 완료 조건에 포함하지 않는다.
