# 4장 전권 재리뷰 잔여 지적 반영 기록

대상은 Claude 전권 재리뷰 run 24의 최종 판정 `소폭 수정 후 사용 가능`에 남은 여섯 지적이다. 산술·논리·게이트 수·경로 깊이에는 오류가 없었으며, 이번 수정은 범위·난이도·중복·인쇄 가독성을 정리한다.

## F1 · 그림 4.1과 직전 표의 중복

- 표는 자리별 입력·출력 값을 검산하는 역할로 유지한다.
- 그림 4.1의 각 상자에서는 `A_i`, `B_i`, `g_i`, `p_i`, `S_i` 전체를 반복하지 않는다.
- 그림은 0번 자리의 `g_0=1` 생성과 1~3번 자리의 `p_i=1` 전파, `c_0`에서 `c_4`로 이어지는 방향만 보여 준다.

## F2 · 서장 그림 1의 다섯 조건과 실행 계획 혼동

- 연산기 수, 신호·연산 시간, 이동 거리·통로 폭, 가까운 저장공간, 비트 수를 다섯 상자로 분리했다.
- 실행 계획은 여섯 번째 조건이 아니라 다섯 조건을 배치·순서·재사용으로 엮은 결과임을 도해와 본문에서 명시했다.
- 다섯 조건을 질문 목록으로 다시 반복하던 문단은 압축했다.

## F3 · 그림 4.2 B패널 인쇄 가독성

- 밀집 도해의 상자 글자를 기존 공통 최소 6.5pt보다 큰 7pt로 고정했다.
- 작은 상자의 폭을 늘리고 `T_1=p_3g_2`를 두 줄로 나누어 수식 주변 여백을 확보했다.
- 자동 검증에 그림 4.2의 7pt 규칙을 추가했다.

## F4 · 교육 모형 면책 문장의 반복

- 추상화 안의 교육용 단위와 실제 칩 사양의 차이는 서장에 공통 원칙으로 한 번 정리했다.
- 1장과 4장의 반복 문장은 삭제했다.
- 2장은 해당 비교에서 실제로 제외한 배선·부하·팬아웃만 짧게 남겼다.

## F5 · 4장 제목과 실제 비교 범위

- 장 제목을 `같은 덧셈도 마지막 올림을 만드는 길은 다르다`로 바꿨다.
- 제목 단계부터 비교 대상이 완성 덧셈기 전체가 아니라 최종 올림 `c_4` 회로임을 드러낸다.
- 본문·계획 문서·PDF 검증 문구를 함께 갱신했다.

## F6 · c1~c4 연속 전개의 기호 부담

- `c_1`, `c_2`, `c_3`을 각각 완전히 펼치는 연속 전개를 본문에서 제거했다.
- 본문에는 비교에 직접 필요한 `c_4`의 다섯 항만 남겼다.
- 재귀 대입 과정은 `선택 읽기` 상자로 분리해 건너뛰어도 다음 게이트 수·경로 비교를 읽을 수 있게 했다.
- 자리별 실제 값은 앞의 표와 그림 4.1이 담당하도록 역할을 분리했다.
