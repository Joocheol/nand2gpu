# 독립 기술·편집 검토 요청

당신은 일반 대중을 위한 컴퓨터 하드웨어·GPU 교양서의 독립 기술 검토자이자 출판 편집자다. 저자의 의도나 기존 리뷰를 무조건 지지하지 말고 기술적 정확성, 교육적 효과, 구조적 인과관계, 시장 차별성, 장기 유효성을 기준으로 비판적으로 검토하라.

## 확정 사항

- 한국어 본제는 **『진리표에서 GPU까지』**로 확정되었다. 제목 후보를 다시 선정하거나 제목을 바꾸라고 제안하지 마라.
- 부제는 미확정이다. 다만 이번 리뷰의 주된 대상은 부제가 아니라 목차와 샘플이다.
- 독자는 프로그래밍·논리회로·컴퓨터구조를 배우지 않은 일반 독자다.
- 코드는 필수 요소가 아니다.
- 핵심 서사는 `조합 → 복제 → 공유 → 데이터 재사용 → 전용화`다.
- 실제 발명의 역사와 독자를 위한 논리적 설명 순서를 구분해야 한다.

## 반드시 검토할 질문

1. 1장이 제목의 약속대로 실제 진리표에서 시작하고, 진리표의 명세와 NAND 구현을 정확히 구분하는가?
2. 진리표 → NAND → 덧셈기·곱셈기 → ALU → 레지스터·클럭·상태 → CPU의 연결에 기술적 공백이나 잘못된 필연성이 있는가?
3. CPU → SIMD → SIMT → warp·wavefront → SM·CU → GPU 메모리 계층의 추상 수준과 용어 도입 순서가 정확한가?
4. 그래픽 파이프라인과 GPGPU가 핵심 서사에 인과적으로 기여하는가, 아니면 우회로인가?
5. 메모리 계층 → 산술 집약도 → 행렬 곱셈 → 타일링 → 행렬 연산 전용화의 연결이 충분히 설명 가능한가?
6. Tensor Core, MFMA, XMX, TPU MXU를 일반 원리의 사례로 다루면서 회사별·세대별 차이를 지킬 수 있는가?
7. 세 샘플의 기술 내용, 계산, 비유, 생략 고지가 정확한가?
8. 초반만 쉽고 후반이 갑자기 전공서가 되는 난이도 절벽이 있는가?
9. 4부 20장과 분량 비율이 일반 교양서로 현실적인가?
10. 기존 국내 GPU·AI 반도체 책과 구분되는 차별성이 목차에서 실제로 구현되는가?
11. 출처 관리대장의 자료 선택·적용 범위·보류 항목에 중대한 결함이 있는가?
12. 반드시 목차 단계에서 고쳐야 할 것과 샘플 집필 이후 판단할 것을 구분하라.

## 지적 형식

각 문제는 반드시 다음 형식으로 작성하라.

- 위치 또는 검토 대상
- 문제의 내용
- 중요도: 높음 / 중간 / 낮음
- 범주:
  1. 반드시 수정해야 하는 기술적 오류
  2. 일반 독자의 이해를 방해하는 설명상의 문제
  3. 책의 구조·시장성·차별성에 영향을 주는 문제
  4. 선택 가능한 표현상의 개선
- 문제가 되는 이유
- 구체적인 수정안
- 수정하지 않을 경우의 위험

기술적 오류와 문체 취향을 구분하라. 세부사항을 늘리는 것이 언제나 더 좋은 해법이라고 가정하지 마라. 대안이 여러 개라면 장단점을 비교하라.

## 출력 구조

한국어로 다음 순서에 맞춰 답하라.

1. 전체 판정: 승인 / 조건부 승인 / 재설계 필요 중 하나
2. 가장 중요한 장점 3개 이내
3. 우선순위가 높은 지적사항
4. 샘플별 판정
5. 출처 체계 판정
6. 목차를 고정하기 전에 필요한 수정 목록
7. 목차 고정 뒤 샘플·도해 단계로 넘겨도 되는 항목
8. 최종 권고

막연한 칭찬은 하지 말고, 근거 없는 시장 전망이나 확인하지 않은 최신 제품 사실을 단정하지 마라.
