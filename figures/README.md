# TikZ 도해 제작 원칙

최종 도해는 『금융공학의 이해』와 같은 방식으로 `figures/*.tex`에 두고 본문에서 `\input`으로 불러온다. 서장·1~5장의 기존 SVG는 내용과 배치 검토 기록으로 보존하며, TikZ 이식이 끝난 도해는 TikZ 파일을 단일 제작 원본으로 삼는다.

## 공통 규칙

- 공통 스타일은 `styles/tikz-diagrams.tex`에만 정의한다.
- 최종 인쇄 글자는 6.5pt보다 작게 만들지 않는다.
- 글자 크기를 우회해 줄이는 `\resizebox`와 `\scalebox`를 TikZ 전체에 적용하지 않는다.
- 진한 회색은 현재 따라갈 경로, 옅은 회색은 배경·명세, 흰색은 일반 요소에 쓴다.
- 방향과 구분은 명암뿐 아니라 선 굵기·선 종류·화살촉·문장으로 중복 표시한다.
- 회로 수치는 그림에 실제로 놓인 교육용 게이트에서 다시 셀 수 있어야 한다.

## 현재 이식 상태

- `preface-01-equation-and-finite-machine.tex`: 한 줄이 정한 결과와 유한한 기계에서 별도로 정할 다섯 조건을 두 패널로 분리했다.
- `preface-02-down-and-up-map.tex`: 진리표까지 내려가는 분해와 GPU·전용화까지 올라오는 배치를 세로 방향으로 분리해 역사 연표처럼 보이지 않게 했다.
- `ch04-02-chain-vs-expanded.tex`: 리플 c4 16게이트·9층과 펼친 c4 22게이트·6층을 B5 가로 전면 폭으로 시험 이식했다. 1층의 동시 생성 게이트는 묶어 표시하고, 이후에는 중간 게이트 사이의 의존선만 그려 선이 상자나 글자를 통과하지 않도록 재배치했다.
